# Course Vectorstore RAG Metadata Fallback

Provide a dynamic metadata fallback for video transcript chunks during query time so that they are correctly annotated and processed by the RAG query engine (e.g., hybrid RRF, BM25, and overview queries).

## Proposed Changes

### Core RAG Query Engine

#### [MODIFY] [vectorstore.py](file:///home/ricky/VScode/projects/python/Django/testings/ai_video_engine/apps/core/services/vectorstore.py)

1. Introduce a helper method `_get_doc_metadata(self, doc) -> dict`:
   - Checks if the document metadata lacks `source_file` but contains `video_title`.
   - If so, it returns an enriched copy with:
     - `source_file = video_title`
     - `file_type = 'video_transcript'`
     - `chunk_role = 'single'`
   - Otherwise, returns the original metadata dict.
2. Substitute all direct references to `doc.metadata` / `d.metadata` / `gdoc.metadata` / `m` with `self._get_doc_metadata(doc)` across:
   - Unique file extraction (overview mode)
   - Metadata filtering (`filter_source_file` and `filter_file_type`)
   - BM25 candidate slot capping
   - Context relevance ordering & injection
   - Retrieved sources serialization
   - Representative chunk per file collection (`_get_one_chunk_per_file`)
   - Parent expansion matching (`_find_parent`)
